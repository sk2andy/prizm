# Arc-inspired vault interface

This personal fork adopts the approved “Favorites and sections” design: a tinted
sidebar with favorite shortcuts, an inset native split view, inline vault-wide
search above its results, and quieter grouped details. Folder and organization
management, keyboard actions, secret handling, and all item types remain available.

The macOS 15 contribution remains separate in upstream PR #88. No additional
upstream PR is requested. The owner approved Luma and a subtly brushed blue shield.

README imagery must come from the running app with fictional, debug-only fixtures.
No screenshots may include the owner's real vault.
